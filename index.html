Signal Case Study

What: AI-powered content moderation tool that instantly detects spam, phishing, and policy violations across 12 risk categories.

Why: With 1+ years of experience in content moderation and Trust & Safety at TELUS International, I identified a gap: manual spam detection is repetitive and pattern-based. I built Signal to automate the exact judgment patterns I apply daily.

How: Uses a rule-based detection system with 200+ keywords organized into semantic categories (Telegram, IPTV, Betting, Crypto, Loans, Phishing, Adult Content, Work-from-Home scams, Counterfeits, and obfuscated text). Calculates risk scores and weights by severity.

Impact: Moderators can paste suspicious content and instantly get structured decisions. Perfect for any platform handling user-generated content.

Escalation Router — Ops Dashboard

Live

An AI-powered triage system that automatically classifies incoming tickets by category, severity, and routing team — turning a live queue of raw reports into structured, actionable data, the same judgment calls I make manually every day in escalation review.

Built to go beyond simple AI text responses (like my chatbot) into structured output — where AI's answer directly drives the app's logic: color-coded severity, routing decisions, and persistent record-keeping, mirroring real Trust & Safety ops tooling.

Try the Dashboard → View Code

How it works: Submit a ticket → backend sends it to Gemini with a structured-output prompt → AI returns JSON (category, severity, routing team, reasoning) → result is saved to Firestore and instantly rendered on the dashboard with a color-coded severity badge. Tickets persist across sessions, loading automatically on page open.

Features:

  • Real-time AI classification into category, severity, and routing team
  • Structured JSON output — AI's response directly drives app behavior, not just displayed text
  • Color-coded severity badges (Low → Critical) for instant visual triage
  • Persistent ticket history via Firebase/Firestore — survives refreshes and new sessions
  • Taxonomy modeled on real content moderation tagging categories from professional Trust & Safety work
  • Secure serverless backend — API key never exposed to the browser
